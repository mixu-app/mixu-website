记住每一个线索，推理留给你。

谜序是一款离线优先的悬疑阅读器。它把你已经读到的内容整理成一张可点击的案情板—— 人物、地点、事件、各执一词的证词，都能跳回原文。它不剧透，不猜凶手，也不替你推理。

看看它怎么工作 （跳到 3 步演示） 在 GitHub 上看客户端 （公开客户端仓库）

三条价值

  1. 只显示你读过的。 案情板按阅读进度过滤：读到第 10 章，就看不到第 14 章才揭晓的身份。
  2. 点一下，回到原句。 每条信息都带原文定位，跳过去、再跳回来，位置不丢。
  3. 不登录也能读完一本书。 导入、阅读、书签、笔记、已下载的图包，全部离线可用。 E-Ink 设备用同一个安装包，只是少一点动画。

适合谁

  • 人物多、时间线绕、隔几天再读就忘了"这人是谁"的长篇推理读者。
  • 喜欢自己做笔记、自己列嫌疑人表的读者。
  • 用墨水屏、只想安静读完一本书的读者。

不适合谁（诚实说明）

  • 想要"AI 直接告诉我凶手"的人：这是产品原则之外的功能。
  • 想要在线阅读、下载书源、绕过 DRM 的人：这不是阅读器的定位。
  • 谜序当前处于开发阶段，本站描述的是设计目标，不是已发布功能。
  • 「不剧透」是工程目标：按阅读进度做确定性过滤，并有可失败的回归测试；它不等于数学保证。
  • 客户端代码开源（Apache-2.0），托管服务与图库另计；书名、品牌与第三方图书内容不在开源许可内。
