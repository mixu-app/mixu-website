クライアントダウンロード

Mixuはオフライン優先のミステリー読書アプリです。ここでは公式Androidクライアント（APK）のダウンロードと、リリース署名およびチェックサムの検証手順を提供しています。

リリース状況

現在はドキュメント先行・開発初期段階のため、公開パッケージ（APK）はまだリリースされていません。

Mixuは「ドキュメント先行・仕様駆動」の原則に従っています。M0（リーダー基盤）およびM1（捜査ボード）のマイルストーン完了後、本ページにて最初の公開Alphaプレビュー版をリリース予定です。

オープンソースクライアントリポジトリの最新の進捗をご確認ください：github.com/mixu-app/mixu-client。

パッケージの真正性と署名検証

端末の安全性を確保し、改ざんされたビルドの実行を防ぐため、ダウンロードしたAPKをインストールする前に必ずSHA-256チェックサムと公式デジタル署名の検証を行ってください。

1. SHA-256 チェックサムの照合

ターミナルでダウンロードファイルのSHA-256ハッシュを計算し、公式マニフェストの値と完全に一致することを確認してください：

Linux / macOS：

sha256sum mixu-app-*.apk

Windows (PowerShell)：

Get-FileHash .\mixu-app-*.apk -Algorithm SHA256

2. 公式デジタル署名検証 (APK Signature Scheme)

Mixuの公式ビルドはリリース証明書を用いてAPK Signature Scheme（v2/v3）で署名されています。Android SDKのapksignerツールを使用して真正性を検証できます： 

apksigner verify --verbose mixu-app-*.apk

検証結果にVerified using v2 scheme (APK Signature Scheme v2): true（またはv3がtrue）が含まれ、証明書のフィンガープリントが公式発表のものと一致する必要があります。

3. 公式リリースチャネルとソースコードビルド

公式パッケージは当サイトおよび公式GitHub Releasesページ（https://github.com/mixu-app/mixu-client）でのみ配布されます。未検証のサードパーティサイトからダウンロードしないでください。クライアントのソースコードを取得し、Android Studio / Gradleでローカルビルドすることも可能です。

「ネタバレなし」は工学的な目標です：読書進度に基づく決定論的フィルタリングと回帰テストによって担保されており、数学的な絶対保証ではありません。
