Package Integrity & Signature Verification

To safeguard your device and avoid tampered builds, verify the SHA-256 checksum and official digital signature before installing any downloaded APK.

1. SHA-256 Checksum Comparison

Compute the SHA-256 hash using local terminal tools and verify it matches the official manifest exactly:

Linux / macOS:

sha256sum mixu-app-*.apk

Windows (PowerShell):

Get-FileHash .\mixu-app-*.apk -Algorithm SHA256

2. Official Digital Signature Verification (APK Signature Scheme)

Official Mixu builds are signed with release certificates using APK Signature Scheme (v2/v3). Use apksigner from the Android SDK to verify authenticity: 

apksigner verify --verbose mixu-app-*.apk

The output must contain Verified using v2 scheme (APK Signature Scheme v2): true (or v3 is true), and the certificate fingerprint must match the officially published fingerprint.

3. Official Release Channels & Source Builds

Official packages are distributed solely via this site and the official GitHub Releases page: https://github.com/mixu-app/mixu-client. Do not download from unverified third-party app stores. You may also clone the open-source client code and build locally with Android Studio / Gradle.

"Spoiler-free" is an engineering objective: deterministic filtering based on reading progress backed by failing regression tests; it is not a mathematical guarantee.
