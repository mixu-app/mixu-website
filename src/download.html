安装包真实性与签名校验

为确保您的设备安全，避免运行恶意篡改版本，在安装从网络下载的 APK 前，请务必进行 SHA-256 校验和核对与官方数字签名验证。

1. SHA-256 校验和比对

在本地终端运行系统工具计算下载文件的 SHA-256 哈希，核对是否与官方清单中给出的校验值完全一致：

Linux / macOS：

sha256sum mixu-app-*.apk

Windows (PowerShell)：

Get-FileHash .\mixu-app-*.apk -Algorithm SHA256

2. 官方数字签名验证 (APK Signature Scheme)

谜序官方构建使用发布证书进行 APK Signature Scheme (v2/v3) 签名。您可使用 Android SDK 提供的 apksigner 工具验证签名真实性： 

apksigner verify --verbose mixu-app-*.apk

验证结果中必须包含 Verified using v2 scheme (APK Signature Scheme v2): true（或 v3 为 true），且证书指纹与官方公布的指纹一致。

3. 官方发布渠道与源码构建

官方安装包仅通过本站及 GitHub 官方 Releases 页面发布：https://github.com/mixu-app/mixu-client。请勿在任何未经验证的第三方应用市场或网盘下载安装包。您也可以直接获取客户端开源代码，在本地使用 Android Studio / Gradle 进行构建。

「不剧透」是工程目标：按阅读进度做确定性过滤，并有可失败的回归测试；它不等于数学保证。
